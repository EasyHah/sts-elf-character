# 卡牌按功能分类（抽牌 / 加费 / 其它）

日期：2026-10-23　规则：蚀面打出后自动封印并**进入弃牌堆**（不再回手）。
“抽牌”包括抽牌、检索、从弃牌堆取回、复制手牌；“加费”包括获得能量、下回合能量、条件减费。
一张牌只要有一面带抽牌或加费就归入对应组；两种都有的单列。括号里是升级后的数值。

| 组 | 张数 |
|---|---|
| 抽牌 | 22 |
| 抽牌 + 加费 | 4 |
| 加费 | 6 |
| 其它 | 40 |
| 合计 | 72 |
