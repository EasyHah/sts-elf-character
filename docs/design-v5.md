# 设计稿 v5：诅咒残留 + 封印效果

日期：2026-10-23　状态：**已实现，未进游戏测试**（第八轮，见 `TEST-RECORD.md`）
基于 v4（`cards-relics-design.md`），只列改动。未提到的牌和规则保持 v4。

## 1. 规则

| 规则 | v4 | v5 |
|---|---|---|
| 两面 | 光面 / 蚀面 | 不变 |
| 侵蚀 N | 手中其他光面牌翻成蚀面 | 不变 |
| 蚀面打出后 | 自动封印，翻回光面，进弃牌堆 | **保持蚀面**，进弃牌堆。诅咒留在牌组里，之后抽到时仍是蚀面 |
| 封印 N | 手中蚀面翻回光面 | 翻回光面，并**触发这张牌的封印效果**。只有封印能把蚀面变回来 |
| 封印效果 | 无 | 每张双面卡的蚀面文字下多一行“封印：……”。即时、免费，**一定弱于蚀面本身** |
| 咒鸣 | 侵蚀、封印、自动封印各 +1 | 侵蚀、封印各 +1（遗物触发的封印也算封印） |
| 反噬 | 回合结束时，手中每张蚀面失去 2 生命 | 不变。蚀面会越积越多，不处理就每回合掉血 |
| 战斗结束 | 全部恢复光面 | 不变 |

**设定上的对应**：诅咒蔓延很容易，净化要付出动作。侵蚀是 0 费的小动作；封印要专门的牌或遗物，但每次都有回报。

**三种打法**

| 打法 | 怎么赢 | 费用 | 过牌 | 伤害 | 防御 |
|---|---|---|---|---|---|
| 暗 · 放任 | 牌组越暗，多段越多（收割蚀面按弃牌堆蚀面数加段）；定神、血之回响、咒之心把反噬变成收益 | 暗契蚀面 +3 能量 | 侵蚀牌附带抽牌 | 最高 | 最弱（蚀面少格挡，还要掉反噬血） |
| 光 · 净化 | 先侵蚀，再批量封印，靠封印效果和翻面咒鸣拿格挡、伤害；大封印光面让每张的封印效果触发两次 | 清修、月辉觉醒：封印给能量 | 回忆：封印抽牌 | 中 | 最高 |
| 循环 | 薄卡组：侵蚀抽牌、封印回能（月辉觉醒），共鸣按咒鸣回能 | 靠回能零件 | 靠抽牌零件 | 无上限 | 靠封印效果 |

**无限的门槛**：蚀面不回手、也不会白白变回光面，两张牌互相侵蚀不再能免费循环。
无限要靠薄卡组 + 抽牌零件 + 回能零件。和原版一样，删到只剩 3 张左右的 0 费过牌时理论上能无限，这属于“拼零件”，可以接受。

## 2. 起始

| 牌 | 费 | 光面 | 蚀面 | 封印效果（升级） |
|---|---|---|---|---|
| 打击 ×4 | 1 | 6 伤害 | 4 伤害 ×2 | 对随机敌人 3（4）伤害 |
| 防御 ×4 | 1 | 5 格挡 | 3 格挡，对所有敌人 3 伤害 | 3（4）格挡 |
| 咒之低语 | 0 | 侵蚀 1，抽 1 | 侵蚀 2 | 2（3）格挡 |
| 单刃斩 | 1 | 7 伤害；本回合翻过面则抽 1 | 3 伤害 ×3 | 本回合下一张攻击 +3（4）伤害 |

**起始遗物 裂纹封印（改）**：每回合打出的**第一张蚀面牌**，结算完后自动封印（触发它的封印效果），再进弃牌堆。
按用户要求“回合第一张打出的牌自动封印，也触发封印效果”实现；只对蚀面生效，因为光面封印不了。如果想改成“第一张牌，不管哪一面”，是一行改动。

**Boss 遗物 完整封印（改）**：替换裂纹封印，每回合前 **2** 张打出的蚀面牌自动封印。

## 4. 其余双面卡的封印效果
